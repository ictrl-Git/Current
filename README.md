# Current FSE Field Knowledge Base

A searchable field-reference project for Current Lighting and NX products.

## Initial scope

- Current and NX product specifications
- NXSW2-GT4 installation and comparison material
- NXAC release notes
- Transfer-device references
- Related integration documentation
- Research backlog for field procedures, firmware matrices, and troubleshooting

## Run locally

Open `app/index.html` in a browser. The initial app is static and works without a server.

## Repository policy

This public repository stores the app, metadata, and original field-authored knowledge. It does **not** store:

- customer or site field reports
- executables, firmware, or encrypted update packages
- large software archives or videos
- third-party documents unless redistribution rights are confirmed

Those materials may be indexed by title and retained in approved private/local storage.

## Status

Version 0.1 establishes the repository structure and initial catalog recovered from the 2026 source archive.
